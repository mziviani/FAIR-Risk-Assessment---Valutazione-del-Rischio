# FAIR-Risk-Assessment---Valutazione-del-Rischio
Modello quantitativo open source conforme a FAIR e ISO 27005:2022 per stimare il rischio cyber e l'Annual Loss Expectancy (ALE) in Euro. Calcola mitigazioni perimetriche/intrinseche, vulnerabilità residua, tempo di ritorno con la distribuzione di Poisson e i costi con dati di Threat Intelligence 2026.
